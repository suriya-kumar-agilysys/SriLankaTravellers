# Mission Sri Lanka 2026

A shareable, responsive static travel poster and funny team email for the team trip to Sri Lanka.

Pages:

- `index.html` - travel poster
- `srilanka-trip.html` - team email and packing checklist

## Publish With GitHub Pages

The repository includes `.github/workflows/pages.yml`. After pushing to the `main` branch, open **Settings > Pages** in GitHub and set the source to **GitHub Actions**.
